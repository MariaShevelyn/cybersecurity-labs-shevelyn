# Лабораторна робота №5: Захищена електронна пошта

Виконала: Шевелин Марія Сергіївна

## Опис програми

Консольний застосунок мовою Python для демонстрації принципів захищеної комунікації та симетричного шифрування електронних повідомлень. Програма дозволяє безпечно обмінюватися листами через SMTP-сервер Gmail, використовуючи персональні дані (спільне секретне слово) для криптографічного захисту тексту від перехоплення.

## Функціонал

* Генерація стійкого криптографічного ключа на основі заданого спільного секретного слова.
* Симетричне шифрування введеного тексту повідомлення з перетворенням у безпечний для пересилання формат Base64.
* Автоматична відправка зашифрованих повідомлень на вказану електронну адресу за допомогою пароля додатка Gmail.
* Отримання та успішне розшифрування прихованого тексту за умови введення правильного секретного слова.
* Інтерактивне консольне меню для зручного перемикання між режимами відправки та розшифрування.

## Запуск

Для роботи потрібен встановлений Python 3 та бібліотека для шифрування. Якщо бібліотека не встановлена, виконайте команду: `pip install cryptography`
