# Лабораторна робота №4: Особистий цифровий підпис

Виконала: Шевелин Марія Сергіївна

## Опис програми

Консольний застосунок мовою Python для демонстрації принципів роботи електронного цифрового підпису та асиметричного шифрування. Програма генерує пару ключів (приватний та публічний) на основі персональних даних користувача, обчислює криптографічний хеш документа, формує цифровий підпис та виконує перевірку цілісності й автентичності файлу.

## Функціонал

* Генерація приватного ключа шляхом хешування персональних даних (прізвище, дата народження, секретне слово) та обчислення математично пов'язаного публічного ключа за допомогою модульної арифметики.
* Обчислення криптографічного геш-відбитка документа (підтримка алгоритмів SHA-256, SHA-512, BLAKE2b).
* Створення цифрового підпису шляхом шифрування хешу документа приватним ключем (операція XOR) зі збереженням у файл.
* Верифікація підпису за допомогою публічного ключа та перевірка незмінності документа.
* Автоматичне тестування стійкості системи до несанкціонованої модифікації тексту документа та спроб підробки підпису без приватного ключа.

## Запуск

Для роботи потрібен встановлений Python 3.13
