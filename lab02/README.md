# Лабораторна робота №2: Захист особистих повідомлень
**Виконала:** Шевелин Марія Сергіївна

## Опис програми
Консольний застосунок мовою Python для демонстрації та порівняння двох класичних алгоритмів шифрування: шифру Цезаря та шифру Віженера. Програма генерує криптографічні ключі на основі персональних даних користувача (сума цифр дати народження для Цезаря та прізвище для Віженера).

## Функціонал
- Шифрування та розшифрування тексту алгоритмом Цезаря.
- Шифрування та розшифрування тексту алгоритмом Віженера.
- Автоматична генерація ключів з введених персональних даних.
- Виведення базового порівняльного аналізу алгоритмів.

## Запуск
Для роботи потрібен встановлений Python 3.
Запустіть скрипт у терміналі:
python cipher_analyzer.py
