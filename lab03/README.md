# Лабораторна робота №3: Стеганографія та аналіз метаданих

Виконала: Шевелин Марія Сергіївна

## Опис програми

Консольний застосунок мовою Python для приховування та вилучення тексту із зображень за допомогою стеганографічного методу найменш значущого біта (LSB). Програма використовує бібліотеку Pillow для маніпуляції з пікселями на рівні каналів RGB, дозволяючи непомітно вбудовувати персональні текстові повідомлення у графічні файли без візуальних втрат якості.

## Функціонал

* Перетворення тексту у двійковий формат (UTF-8) для подальшого приховування.
* Вбудовування повідомлень у молодші біти RGB-каналів зображення (LSB).
* Вилучення, декодування та перевірка прихованого тексту зі створеного стегоконтейнера.
* Автоматичний математичний аналіз змін (підрахунок кількості змінених пікселів, каналів та різниці у розмірі файлів).
* Збереження результату у форматі без втрат (PNG) для запобігання пошкодженню даних.

## Запуск

Для роботи потрібен встановлений Python 3 та бібліотека Pillow. 
Якщо бібліотека не встановлена, виконайте команду: `pip install Pillow`
