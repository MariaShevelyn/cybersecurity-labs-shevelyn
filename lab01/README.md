Лабораторна робота 1: Аудит власної цифрової безпеки
Виконала: Шевелин Марія Сергіївна

Опис програми
Консольна програма мовою Python для аналізу надійності паролів. Програма враховує правила соціальної інженерії та перевіряє, чи не містить пароль персональних даних користувача (імені, прізвища, дати народження). Також реалізована перевірка на наявність поширених словникових слів.

Запуск
Для роботи потрібен встановлений Python 3.13
Запустіть скрипт у терміналі: python password_analyzer.py
